# Detrás de la pantalla

Actividad individual de modelado de datos, de una hora.

Cada persona reconstruye la base de datos que hay detrás de una app de uso diario, a partir de una pantalla y cuatro reglas del negocio. Son siete etapas interactivas (emparejar conceptos, llevar fichas a sus cajas, marcar claves, armar el diagrama entidad-relación, armar las tablas y cazar errores) que se suben y se califican al instante. Al final, la plataforma entrega un reporte para imprimir o guardar en PDF.

- No necesita instalación ni cuentas: se abre `index.html` en el navegador.
- El avance se guarda en el dispositivo.
- El contenido va cifrado: cada etapa se abre al resolver la anterior.
