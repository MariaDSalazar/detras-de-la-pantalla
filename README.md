# Detrás de la pantalla

Actividad de modelado de datos para trabajar en equipo durante una hora.

Cada equipo reconstruye la base de datos que hay detrás de una app de uso diario, a partir de una pantalla y cuatro reglas del negocio. Son siete etapas (conceptos, entidades, atributos, claves, relaciones, tablas y caza de errores) que se suben y se califican al instante. Al final, la plataforma entrega un reporte para imprimir o guardar en PDF.

- No necesita instalación ni cuentas: se abre `index.html` en el navegador.
- El avance se guarda en el dispositivo: un dispositivo por equipo.
- El contenido va cifrado: cada etapa se abre al resolver la anterior.
